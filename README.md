# Sleep Like a Monk

A single-page, scroll-driven site for the **Sleep Like a Monk™** corporate
wellness programme by 5 Pillars.

Static: `index.html` + `styles.css` + `motion.js` + `app.js` + `assets/`.
No build step. GSAP + ScrollTrigger + Lenis load from CDN.

## Run locally
```
python -m http.server 8000
# open http://localhost:8000
```

## Deploy
Zero-config static deploy on Vercel — import the repo, no framework, output
directory is the repo root.
